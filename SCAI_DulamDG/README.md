This repository has the code for New knowledge source pipelines for sociocultural representations in a cognitive architecture (ACT-R). This work is built upon [ICCM-25_RayD](https://github.com/THiCC-Lab/paper-repos-pub/tree/main/ICCM-25_RayD).

We use a small pipeline to connect a knowledge source (ConceptNet/LLama) to represent the world-knowledge specifically targetting sociocultural knowedge as declarative memory wihin ACT-R using [Holographic Declarative Memory](https://doi.org/10.1111/cogs.12904) module (Kelly M.A. et al 2020) rather than ACT-R's in-built Declarative Memory (DM), and build an ACT-R model for IAT task.

# Folder organization.

- `ACT-R` models folder had the .lisp files for IAT task and the model. After running ACT-R from step 2 mentioned above, you should navigate to this folder location from ACT-R consolde.
- `Data` folder has four sub-folders housing all the input corpora and output files generated along with scripts that were used to generate inputs.
  - `Scripts` folder has python notebooks to generate corpora from ConceptNet, LLama and finally a script to analyze the csv files generated after running hdm pipelines.
    - The `ConceptNet_data_gen.ipynb` requires that ConceptNet API is up and running. The conceptNet can be downloaded and installed from this repo [commonsense/conceptnet5: Code for building ConceptNet from raw data.](https://github.com/commonsense/conceptnet5)
    - The `LLM_data_gen.ipynb` requires a huggingface token to use the llama model.
  - `Inputs` folder has the `seed words.txt` file which has the three sets of input words for our three experimental conditions. The `ConceptNet` folder has the corpora generated from ConceptNet -- the text files for text inputs and pickle files for chunked inputs and LLM.
  - `preprocessed inputs` folder has intermediate files generated by running hdm pipeline, which is useed in the later step in the same pipeline.
  - `Outputs` folder has the csv files generated in various experimental configurations. These files are used by the analysis script to generate the plots/graphs we used.
- `HDM-ACT-R` folder was taken from [ICCM-25_RayD](https://github.com/THiCC-Lab/paper-repos-pub/tree/main/ICCM-25_RayD) with slight modifications to accomodate the chunked inputs and performance enhancements. This folder has two python notebooks.
  - The `run_hdm_text_pipeline.ipynb` has the pipeline script that takes text corpus as input.
  - The `run_hdm_chunk_pipeline.ipynb` has the pipeline script that takes chunked corpus as input.
- `Images` folder has jpg version of images used in article.

# Overview of Pipeline (How to use this repo)

1. If you want to manually generate inputs, use scripts in `Data/Scripts`. (or use the inputs in `Data/Inputs`). (Keep in mind that ConceptNet notebook expects ConceptNet is locally built on your machine and the postgres server was started to generate inputs. The concptNet API was rcently decommissioned, so you will have to manually build it in your local machine by navigating to their github (https://github.com/commonsense/conceptnet5))
2. Run the main pipeline script as given below (next heading "To run the main pipeline script" ).
3. Use the `Scripts\analysis and graphs.ipynb` to generate the d-scores and related graphs.

# To run the main pipeline script.

1. Download standalone ACT-R for your operating system from [ACT-R » Software](https://act-r.psy.cmu.edu/software/).
2. Install it for your operating system and run the ACT-R GUI.
3. Follow the instructions in `SCAI_DulamDG\HDM-ACT-R\run_hdm_text.ipynb` to run the notebook. This will generate one csv file "hdm-iat.csv". ( We ran this 100 times for each configuration to obtain data)
