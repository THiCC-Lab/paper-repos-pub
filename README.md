# paper-repos-pub

Repository holding public code and/or data for published papers coming out of the THiCC Lab


- Folder `ICCM-25_RayD` has the HDM ACT-R code for the paper "Ray, M. and Dancy, C. L. (2025). Adapting a vector-symbolic memory for lisp act-r. In 23rd International Conference on Cognitive Modeling."

    This folder is also the prerequisite for`SCAI_DulamDG`

- Folder `ISTAS-25_Beyene` has code for the paper "Beyene, F. S., & Dancy, C. L. (2025, September). Layout-Aware OCR for Black Digital Archives with Unsupervised Evaluation. In *2025 IEEE International Symposium on Technology and Society (ISTAS)* (pp. 1-5). IEEE."

- Folder `SBP-BRiMS-21_AtkinsBD` has the code for the paper "Atkins, A. A., Brown, M. S., & Dancy, C. L. Examining the Effects of Race on Human-AI Cooperation. In proceedings of the 14th International Conference on Social Computing, Behavioral-Cultural Modeling, & Prediction and Behavior Representation in Modeling and Simulation, Virtual, pp. 279-288 (2021)."

- Folder `SCAI_DulamDG`has the code for the article titled "New knowledge source pipelines for sociocultural representations in a cognitive architecture"

- Folder `The STRONG-R`has the data related to "Workman, D., Dancy, C. L., & Mir, D. J. (2025, June). How Carceral Algorithms Distort Black Narratives: The STRONG-R Case Study. In *2025 IEEE International Symposium on Ethics in Engineering, Science, and Technology (ETHICS)* (pp. 1-2). IEEE."
